# テスト方針

- pytest を使う。設定は `pyproject.toml`（`src` を import パスに追加）。
- ロジックは、架空のポケモン数匹だけの `Converter` を使って、結果が一意に決まる形で検証する。
- 仕様の例（あらたな→コマタナ など）は実データ `data/pokemon.json` を使い、**候補に入るかどうか**を検証する。
  第1候補になるかどうかは一致度の調整で変わるので、テストでは固定しない。

| ファイル | 対象 |
|---|---|
| tests/test_kana.py | かな変換、モーラ分割、母音と行の判定 |
| tests/test_scoring.py | 1音の一致度の優先順位、ー・っ の省略、ポケモン側を省略しないこと、末尾の余分な音 |
| tests/test_segmenter.py | 区切り、組合わせ候補と個別候補の数、同点時の扱い、序列ごとの重複除外、仕様の例 |
| tests/test_song.py | 入力チェック、フレーズID、重複モードとチャンネル、ロック、候補の選択と手入力、合体・分割、グループ、JSON の往復と version 1 の読み込み |

CLI（cli.py）は自動テストの対象外で、手動で動作を確認する。
