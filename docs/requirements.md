# 要件・仕様

ひらがなで入力したフレーズ（歌詞）を、音の近いポケモン名（1匹以上の組み合わせ）に変換する。
既存の曲の歌詞をポケモンの名前で歌えるようにすることが目的。現段階はコンソールアプリで変換ロジックを検証している。

## 用語
- **フレーズ**: 入力できるテキストの単位。
- **曲**: 複数のフレーズをまとめたもの。
- **音**: モーラ。拗音（しょ、でゅ 等）は1音、っ・ん・ー はそれぞれ1音。
  直前と同じ母音の小書き文字（ピィ、ケーシィ）は伸ばす音として独立した1音とする。
- **組合わせ候補**: フレーズの区切り方（例「4音 + 3音」）。
- **枠**: 区切った各区間。枠ごとに個別ポケモン候補を持つ。

## 入力
- フレーズはひらがなと「ー」で入力する。空白は取り除き、「～」「〜」「-」は「ー」として扱う。

## 音数の扱い
- フレーズとポケモンの音数は一致させる。ただし次の例外がある。
- **フレーズ側**の ー・っ は、あってもなくてもよい音として扱う（減点なし）。ん は常に1音として数える。
  - だれもーが → 5音（プロトーガ）としても4音（サボネア）としても扱う
- **ポケモン側**の音は省略しない（でるぞ → ケムッソ は不可）。
  - 例外: フレーズ最後の枠のポケモンの最後の1音が ー・ッ・ン のときは、余分な1音として許す（減点なし）。
    ただし、フレーズの末尾が ー・っ・ん の場合は適用しない。
  - 例: たどりつくばしょ → スコルピ + クマシュン
- フレーズの ー・っ の位置からは区切らない（区間の先頭に ー・っ が来る区切りは作らない）。

## 一致度
1音ずつ比べた件数を、次の優先順位で辞書式に比較する（上の項目の件数が多い方を優先）。
1. 完全一致
2. 母音一致
3. 同じ行（濁音・半濁音は清音と同じ行。例: か/が、は/ば/ぱ）
4. 異なる母音の優先度1〜3

| フレーズ側の母音 | 優先1 | 優先2 | 優先3 | 加点なし |
|---|---|---|---|---|
| あ段 | え段 | い段 | う段 | お段 |
| い段 | え段 | あ段 | う段 | お段 |
| う段 | え段 | お段 | あ段 | い段 |
| え段 | あ段 | い段 | お段 | う段 |
| お段 | あ段 | う段 | え段 | い段 |

- ポケモン側の ー は直前の音の母音として扱う。っ・ん は完全一致のときだけ加点する。
- 組合わせ候補の一致度は、各枠の第1候補の一致度の合計とする。同点なら匹数が少ない方を上にする。

## 候補
- 1フレーズにつき組合わせ候補は最大2つで、一致度が高い順に並べる。
- 各枠の個別ポケモン候補は最大3匹（第1〜第3序列）。
- 使う組合わせ候補と、各枠で使う個別候補を選べる。

## 重複禁止モードとチャンネル
- 重複を許すモードと許さないモードを曲全体で切り替えられる（既定は許すモード）。
- 各フレーズは重複チャンネル（1以上の整数。既定は 1）を持つ。
- 許さないモードでは、**同じチャンネルのフレーズどうし**で、**個別候補の同じ序列**に同じポケモンが出ないようにする。
  同じフレーズの別の組合わせ候補や、別の枠どうしでも同じ扱い。チャンネルが違えば重複してよい。
  - 例: どこかの枠の第1候補がマリルなら、同じチャンネルの他の枠の第1候補にはマリルを入れない（第2・第3候補なら可）。
  - 手入力したポケモンは第1序列として扱う。
  - 全フレーズのチャンネルがバラバラなら、重複を許すモードと同じ動きになる。
- 許すモードでは、チャンネルは無視する。
- 一括変換はフレーズ順 → 組合わせ候補順 → 枠順に決める。対象外のフレーズ（ロック中など）の候補は先に押さえる。
- 1フレーズだけ変換するときは、同じチャンネルの他のフレーズの現在の候補をすべて除外の対象にする。

## ロック
- フレーズの変換結果をロックできる。ロック中は変換・候補の選択・手入力・合体・分割ができない。
- 一括変換（曲全体／グループ）ではロック中のフレーズを飛ばす。チャンネルの変更はロック中でもできる。

## 手入力
- 枠ごとに、一覧にあるポケモンを名前（カタカナ表記）または読み（ひらがな）で指定できる。音数や一致度は問わない。
- 手入力したポケモンが、その枠の選択中の結果になる。候補から選び直すと、またはフレーズを変換し直すと消える。

## 合体・分割
- **合体**: 連続した2つ以上のフレーズを、歌詞の順のまま1つにする。
  各フレーズの選択中の組合わせ候補を連結して、1つの組合わせ候補として引き継ぐ（各枠の候補・選択・手入力もそのまま）。
  1つでも未変換のフレーズがあれば、合体後は未変換になる。チャンネルとグループは先頭のフレーズのものを引き継ぐ。
- **分割**: 先頭から何文字目の後ろで分けるかを指定して、必ず2つに分ける。拗音の途中では分けられない。
  分けた2つのフレーズは、どちらも変換結果が消える。チャンネルとグループは分割元のものを引き継ぐ。

## グループ
- 複数のフレーズをまとめてグループにできる。1つのフレーズが入れるグループは1つまで。
- グループに対して、変換（メンバーを歌詞の順に）、チャンネルの設定、ロック／解除ができる。
- 解除するとグループだけが消え、フレーズは残る。メンバーが0になったグループは自動で消える。

## ポケモンの名前
- 図鑑の名前（species 単位）を使う。フォルム違い・リージョンフォーム・メガシンカ・ゲンシカイキは扱わない。
- 特殊な読み（data/reading_overrides.json）: ポリゴン２=ぽりごんつー、ポリゴンＺ=ぽりごんぜっと、
  ニドラン♂=にどらんおす、ニドラン♀=にどらんめす。「・」「：」は取り除く。

## データ
